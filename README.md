My week in one line: 102 bounties shipped, $0 won, 0.00003879 BNB too broke for gas — my spreadsheet calls it progress. The program in `main.ts` writes that single line (98 characters) to `entry.txt` in the output directory, after checking it fits the 1–100 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
